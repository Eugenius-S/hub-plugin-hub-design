# Канвас дизайна: плагин Agents Hub

Открывает HTML-дизайн прямо в хабе, рядом с чатом дизайнера. Тыкаете в точку и пишете коммент, двигаете элемент руками — правки уходят сессии одной пачкой, файл правит она сама.

## Как это работает

1. Слева — «Канвас дизайна». Файл выбирается из последних HTML сессии или кнопкой у пути в чате.
2. **Смотреть** — дизайн как в браузере, со своими шрифтами, видео и анимацией. Размер — по окну, 1440, 1280, 768, 390.
3. **Коммент** — клик по элементу ставит пин, к нему пишется текст. Пины копятся справа в пачке.
4. **Двигать** — тяните элемент, ручкой в углу меняйте размер, двойной клик по тексту — правка текста. ↑ выбирает родителя, ↺ возвращает как было.
5. **Отправить** — сессии уходит одно сообщение: к каждому пину селектор, текст элемента и координаты, к каждой правке «было → стало» в px.
6. Сессия поправила файл — предпросмотр сам перезагрузится, пины прошлого раунда погаснут.

Черновики живут в браузере до отправки: перезагрузка страницы их не теряет.

## Поставить

«Настройки» → «Плагины» → вставить ссылку на этот репозиторий → «Проверить и поставить». Нужны Python 3 и браузер на том же компьютере, что и хаб: предпросмотр идёт с `localhost`.

## Как устроено

Процесс плагина (`server.py`) слушает `127.0.0.1` на порту страницы хаба + 11 (8787 → 8798, другой — `DESIGN_CANVAS_PORT`) и отдаёт файлы веба из рабочих папок сессий и проектов хаба, без скрытых. В HTML он подкладывает `agent.js`: тот рисует рамки и пины поверх дизайна и говорит со страницей хаба через `postMessage`. Свой адрес нужен, чтобы скрипты дизайна не работали с правами страницы хаба; встраивать себя он даёт только ей, запросы с чужих сайтов отклоняет.

## Ограничения

- Только с того же компьютера: по сети (tailnet, телефон) предпросмотра нет.
- В сообщении — селектор и координаты, без снимка элемента.

## Тесты

`PYTHONPATH=<код хаба> python3 -m unittest discover -s tests` — сервер, манифест и логика (`node --test`), без браузера.
