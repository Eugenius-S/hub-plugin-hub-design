# Hub Design: плагин Agents Hub

Открывает HTML-дизайн прямо в хабе, рядом с чатом дизайнера. Ставите пины с текстом, двигаете и правите элементы руками, рисуете стрелки — всё уходит сессии одной пачкой, файл правит она сама.

## Как это работает

1. Слева — чат с сессией дизайнера (её реплики и поле ввода), вкладка «Комментарии» — пачка черновиков. Справа — вкладки «Файлы дизайна» и открытого файла; файл берётся из последних HTML сессии или из списка папки.
2. **Комментарий** — клик по месту ставит пин с текстом.
3. **Правка** — тяните элемент, угол меняет размер, двойной клик по тексту правит его; справа панель стилей: шрифт, цвет, размеры, раскладка, отступы, рамка. ↑ выбирает родителя, ↺ возвращает как было. Отменить и повторить — в тулбаре.
4. **Рисунок** — обведите или покажите стрелкой.
5. **Окно** — ширина дизайна: по окну, 1440, 1280, 768, 390; рядом масштаб.
6. **Отправить дизайнеру** — одно сообщение: к каждому пину селектор и координаты, к правке «было → стало», к рисунку — тип и место. Текст из поля ввода уходит вместе с пачкой.
7. Сессия поправила файл — предпросмотр сам перезагрузится, пины прошлого раунда погаснут.

«Показать» открывает дизайн в новой вкладке, «Поделиться» копирует путь к файлу.

Черновики живут в браузере до отправки: перезагрузка страницы их не теряет. Данные плагина прежних версий (design-canvas) подхватываются один раз.

## Поставить

«Настройки» → «Плагины» → вставить ссылку на этот репозиторий → «Проверить и поставить». Нужны Python 3 и браузер на том же компьютере, что и хаб: предпросмотр идёт с `localhost`.

## Как устроено

Процесс плагина (`server.py`) слушает `127.0.0.1` на порту страницы хаба + 11 (8787 → 8798, другой — `HUB_DESIGN_PORT`) и отдаёт файлы веба из рабочих папок сессий и проектов хаба, без скрытых. В HTML он подкладывает `agent.js`: тот рисует рамки, пины и рисунки поверх дизайна и говорит со страницей хаба через `postMessage`. Свой адрес нужен, чтобы скрипты дизайна не работали с правами страницы хаба; встраивать себя он даёт только ей, запросы с чужих сайтов отклоняет.

## Ограничения

- Только с того же компьютера: по сети (tailnet, телефон) предпросмотра нет.
- В сообщении — селектор и координаты, без снимка элемента; рисунок — описанием.
- Тёмной темы и экспорта нет.

## Тесты

`PYTHONPATH=<код хаба> python3 -m unittest discover -s tests` — сервер, манифест; `node --test tests/lib.test.mjs` — логика. Без браузера.
